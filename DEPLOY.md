# Deploy notes

This folder is the BKS Odisha V2 Next.js app (www.bksorissa.org).

In Vercel: create a new project, set **Root Directory** to `bks-orissa`, Framework Next.js.
Alias `bksorissa.org` / `www.bksorissa.org` when DNS is ready.

Interim hero/media stills are YouTube defaults until Facebook album files are dropped into `public/assets/`.
