## Brand rules

- Same BKS brand, colours, template and nav philosophy as West Bengal
- Languages: **English / Hindi / Odia** (not Bengali)
- Do not invent contact details, district representatives, or BKS designations
- Featured leadership: Smt. Nibedita Nayak Baliarsingh (verified public material only)
